Job Autofill — your profile

Everything here is stored only in this browser (chrome.storage.local). Nothing is sent anywhere. The extension fills forms but never submits them.

Resume file

Uploaded automatically to resume fields on application pages. PDF or Word, up to 4 MB. A PDF is also read for your work-experience bullet points, which are filled into the Description boxes. Upload the resume you are using for the application.

Import / export JSON

Paste a profile as JSON (see sample-profile.json for the shape), then load it into the form below. You still need to press Save profile afterwards. Basic details, Work experience, Education, Common answers and Self-identification are locked and never read from JSON.
